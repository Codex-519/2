# Nova — Windows AI Voice Assistant

Nova is a modular desktop voice assistant for Windows. It listens through the
laptop microphone, understands English/Hindi/Hinglish, answers through Gemini,
and speaks with an installed Windows female voice.

The automation layer is intentionally allowlisted. Nova never executes shell
commands generated by an AI model.

## Features

- Wake word: **“Hey Nova”**
- Manual listening toggle: **Ctrl + Space** or the button in the window
- Speech-to-text using Google Speech Recognition by default
- Optional offline Vosk recognition
- Gemini AI provider with configurable model name and base URL
- Optional Ollama provider for local/offline AI conversations
- Windows SAPI voices through `pyttsx3`
- Conversation context for the current session
- Safe commands for Chrome, YouTube, Google, VS Code, File Explorer,
  Notepad, Calculator, date/time, text files, screenshots, and media keys
- Hindi, Hinglish, and English command patterns
- Recoverable microphone, internet, AI, TTS, and Windows permission errors

## Windows installation

1. Install **Python 3.11 or newer** from https://www.python.org/downloads/windows/.
   During setup, enable **Add python.exe to PATH**.
2. Open PowerShell in this `nova_assistant` folder.
3. Create and activate a virtual environment:

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, run:

   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```

4. Install Python packages:

   ```powershell
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

5. Copy `.env.example` to `.env`:

   ```powershell
   Copy-Item .env.example .env
   ```

6. Allow Python to use the microphone in **Windows Settings → Privacy &
   security → Microphone**.

## Gemini AI

Nova uses Gemini through Google's Generative Language REST API. Create a
Gemini API key in Google AI Studio, then put it only in your local `.env` file:

```dotenv
AI_PROVIDER=gemini
GEMINI_API_KEY=your-key-goes-here
GEMINI_MODEL=gemini-2.5-flash
```

Never commit `.env` or paste the key into source code. The included `.gitignore`
already excludes `.env`.

## Optional local AI with Ollama

1. Install Ollama for Windows from https://ollama.com/download/windows.
2. Open a new PowerShell window and download a small model:

   ```powershell
   ollama pull llama3.2:3b
   ```

3. Confirm the model works:

   ```powershell
   ollama run llama3.2:3b
   ```

4. Set `AI_PROVIDER=ollama` and `OLLAMA_MODEL=llama3.2:3b` in `.env`.
   You can replace the model with another model installed in Ollama.

Ollama runs locally and does not require an API key. Gemini and the default
Google speech recognizer require internet. For offline speech recognition,
see the Vosk section below.

## Start Nova

From the project folder with the virtual environment activated:

```powershell
python main.py
```

Say **“Hey Nova”** and then your command. You can also press **Ctrl + Space**,
click **Start listening**, or type into the chat box and press Enter.

## Configure the female voice

Nova uses Windows SAPI voices via `pyttsx3`. Open **Settings** inside Nova to
see every installed voice and choose one for the current session. To keep a
voice after restarting, copy its full voice ID into `.env`:

```dotenv
TTS_VOICE_NAME=HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Speech\Voices\Tokens\...
TTS_RATE=175
TTS_VOLUME=1.0
```

If no voice is configured, Nova automatically prefers voices whose Windows
metadata includes names such as Zira, Samantha, Hazel, or Heera. For a
different natural-sounding voice, install a Windows language/voice pack in
**Settings → Time & language → Speech** and select it in Nova.

## Configure the assistant name

Edit `.env`:

```dotenv
ASSISTANT_NAME=Nova
WAKE_WORD=hey nova
```

The UI and AI personality use `ASSISTANT_NAME`. The microphone listener uses
`WAKE_WORD`, so update both if you want a different wake phrase.

## Offline speech recognition with Vosk

1. Install the optional package:

   ```powershell
   python -m pip install vosk
   ```

2. Download a Vosk model from https://alphacephei.com/vosk/models.
   An English model is the easiest starting point; a Hindi model is available
   for Hindi-first usage. Extract it somewhere such as
   `C:\Models\vosk-model-small-en-in`.
3. Update `.env`:

   ```dotenv
   STT_PROVIDER=vosk
   VOSK_MODEL_PATH=C:\Models\vosk-model-small-en-in
   ```

Vosk is fully offline, but recognition quality and language coverage depend on
the model you download. A multilingual Whisper-based provider can be added later
behind the same `SpeechToText` interface.

## Add a new safe voice command

1. Add a pattern in `assistant/commands.py` inside `CommandRouter.detect`.
2. Return a `CommandIntent` with a fixed action name and validated arguments.
3. Implement only an allowlisted action in `assistant/automation.py`.
4. Add the action to `CommandRouter.run`.

Do not pass natural-language text to `subprocess`, `os.system`, PowerShell, or
Command Prompt. `subprocess.Popen` is only used with fixed executable names in
`SafeAutomation.APP_ALIASES`.

## Troubleshooting

### Microphone unavailable

- Check **Settings → Privacy & security → Microphone**.
- Close apps that may have exclusive microphone access.
- Check the selected Windows input device under **System → Sound → Input**.
- Run `python -c "import sounddevice as sd; print(sd.query_devices())"` to list
  available devices.

### “Speech recognition needs an internet connection”

Google transcription needs internet. Either reconnect, or install/configure
Vosk as described above.

### Gemini unavailable

- Confirm `GEMINI_API_KEY` is present in the local `.env` file.
- Check that the key is active in Google AI Studio.
- Check `GEMINI_MODEL` and `GEMINI_BASE_URL`.
- Confirm the computer has internet access.

### Ollama unavailable

- Confirm Ollama is running.
- Run `ollama list` and check that the configured model exists.
- Check `OLLAMA_URL` and `OLLAMA_MODEL` in `.env`.

### No female voice or TTS failure

- Confirm `pyttsx3` installed successfully.
- Install a Windows speech voice pack.
- Open Nova Settings and select an installed voice.
- Remove `TTS_VOICE_NAME` from `.env` to use automatic voice selection.

### An application does not open

Chrome and VS Code must be installed and available on the Windows PATH. Notepad,
Calculator, and File Explorer are built into Windows. Nova reports the error
instead of trying arbitrary commands.
