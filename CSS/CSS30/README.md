# Aurelian Market

A modern ecommerce storefront and Node.js/Express backend scaffold for a real-world online shop.

## Features

- Premium shopping UI built with HTML, CSS, and JavaScript
- Responsive product listing, cart, wishlist, checkout, and profile pages
- MongoDB-ready Mongoose models for users, products, orders, and reviews
- JWT-ready authentication middleware and routes
- Razorpay integration-ready payment route with environment-variable placeholders
- Cloudinary-ready image strategy for product uploads

## Quick start

1. Install dependencies:
   npm install
2. Create a `.env` file from the included template.
3. Start the backend:
   npm start
4. Open the frontend from the `client/` folder in a browser.

## Project structure

- `client/` — storefront pages, styles, and frontend scripts
- `admin/` — admin dashboard and management pages
- `server/` — Express API, database config, and models
